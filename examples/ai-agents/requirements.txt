# `python-deps-resolve.yml` triggers on `**/requirements.txt`, so it ran on every change to
# this file, went green, and resolved seven OTHER files (#3486). Measured in

#   1. azure-ai-projects==1.0.0b3   vs  semantic-kernel 1.39.4 depends on
#                                       azure-ai-projects~=1.0.0b12       (RC=1)
#   2. pydantic==2.10.2             vs  semantic-kernel 1.39.4 depends on
#                                       pydantic!=2.10.0,!=2.10.1,!=2.10.2,!=2.10.3,
#                                       <2.12,>=2.0                       (RC=1)
#
# Both are the same accident: an exact pin taken at one moment against a library that has
# since moved its floor. `azure-ai-projects` in particular is a TRANSITIVE dependency of

# newest release inside each declared range: azure-ai-projects 1.0.0b12 (the `~=1.0.0b12`
# floor) and pydantic 2.11.10 (the newest 2.11.x, i.e. under the `<2.12` ceiling and clear
# of the four excluded 2.10.x patches).
#
# With those two, `pip install --dry-run -r requirements.txt` in python:3.11-slim exits
# RC=0 and reports 132 packages. The file is in the resolve matrix now, so the next drift
# reds a PR instead of shipping.
