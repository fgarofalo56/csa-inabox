# API & AI Gateway Plane — operator decisions recorded 2026-10-28

Answers given in chat by the operator during planning, in two rounds of four
questions each. Where an answer differs from the recommended default, the
consequence is stated so a later reader sees why a wave carries an extra
constraint. These are fixed inputs for every wave; a wave that wants to depart
from one files a Q-item in `RISKS-AND-OPEN-DECISIONS.md` and waits.
