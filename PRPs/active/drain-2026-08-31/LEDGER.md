Companion to `PRP.md`. **Every open issue appears here exactly once.** An issue
absent from this table is a gap in the program, not an issue that does not matter.

Measured 247 open issues on 2026-08-31. Generated by
`PRPs/active/drain-2026-08-31/gen-ledger.py` from a live `gh issue list`
snapshot (`open-issues-2026-08-31.json`, same directory) — re-run it rather
than hand-editing rows.

**Per-issue file lists live in `FILES.md`**, not here. A row in this table names a
lane; the register in `FILES.md` names the files that lane may touch, with the
provenance of each list. `OWNERSHIP.md` §8 requires the file list before a lane opens.

## Verification freshness

A verdict is only as good as the measurement behind it, and the measurements here
were taken across several windows. Rows whose note ends **`INHERITED - not
re-verified at head`** carry a verdict measured in an earlier window and relayed —
not re-measured against the current tree. They are recorded as findings because the
original measurement was real, and flagged because a carried finding is a
**hypothesis** until re-measured.

The re-verification lane for #4073 / #4064 / #4038 / #4036 / #4035 / #4030 disclosed
this itself: of the 23 rows it reported, **exactly one — #4036 — was measured in that
run.** The remaining 22 survived a plausibility check and nothing stronger. That is
why #4036 carries a file-and-line note and the others carry a provenance flag.

**#4035 has since been closed out.** It was re-read at head 2026-08-31 and is `REAL`,
and larger than the row it replaced: three regressions rather than one, on a path that
is not where the earlier note said it was. That is one carried hypothesis converted to
a measurement — and the one conversion changed both the severity and the file.
**#4064 was re-measured at head 2026-08-31 and is `REAL`** — the `byRepo` bucketing
and the manufactured-UNKNOWN message are both still present in
`reconcile-policy.mjs:328` — so no `PENDING-REVERIFY` rows remain.

**156 rows carry verdicts from the 2026-08-31 agent-triage sweep** — 16 read-only
lanes of ten issues or fewer, each instructed to re-measure the issue's central
claim at head (file:line or a live `gh run`/API read) before classifying; the merge
reconciled 156/156 with zero missing, zero conflicting duplicates, zero invalid
verdicts. Those rows live in `triage-agent-verdicts.json` beside this generator;
a hand-curated entry in the script's V dict outranks them. They are one rigor tier
below a hand verdict — per `DEV-LOOP.md` §10 box 1, a lane still re-measures its
own issues at head before writing code.

**Consequence for scheduling:** a lane re-measures its own issues at head before
writing code (`DEV-LOOP.md` §10, box 1). An `INHERITED` row is schedulable; it is not
actionable until that box is checked.
